# 小回·天气关怀（astrbot_plugin_xiaohui_weather_care）

本机自建插件。目标：**前一天晚上用自然语言提醒第二天的天气**（带伞/添衣），
并且**只在真的值得提醒时开口**；平时你主动问天气时，小回也能自然调用工具回答。

## 做什么

1. **按需天气工具**：注册 LLM 工具 `get_weather`（数据源 Open-Meteo，零 Key）。
   你问"明天要不要带伞"，对话模型会自行调用并自然回答。
2. **前一天条件提醒**：每天到点（默认 21:00）检查一次：
   - `|明天最高温 − 今天最高温| ≥ 3℃`，或
   - `|明天最低温 − 今天最低温| ≥ 3℃`，或
   - `明天降雨概率 > 80%`
   命中任一 → 生成一句事实（如"明天示例城市会降温…记得添衣"）并发提醒；
   **不命中 → 什么都不做**。

## 关键设计：提醒交给 xavier_reminder 发

本插件**不自己发消息、不自己调 LLM、不自己写历史**。命中后，它只是向
`xavier_reminder` 的存储里**落一条即时提醒**（`type=once`），由 reminder 走它
那条"伪造消息注入完整管线"的成熟路径。因此自动继承：

- 意识同步期间的 `suppress_occurrence` 拦截；
- 与 `wakeup` 主动消息的 10 分钟合并窗口；
- 消息防抖动 / 分段 / 中文表达保护等既有链路。

判断全部在代码里做（`logic.py`），不依赖模型做算术。

## 配置

在 AstrBot WebUI（`127.0.0.1:2140`）→ 插件管理 → 本插件 → 配置，或直接改
`data/config/astrbot_plugin_xiaohui_weather_care_config.json`。

| 项 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 开关"前一天条件提醒" |
| `location_name` | 示例城市 | 只影响话术 |
| `latitude` / `longitude` | 39.9042 / 116.4074 | 真正决定查哪里的天气 |
| `check_time` | 21:00 | 每日检查时间 |
| `check_window_minutes` | 90 | 错过窗口不补发 |
| `temp_delta_threshold` | 3.0 | 温差阈值（℃） |
| `precip_probability_threshold` | 80 | 降雨概率阈值（%，严格大于） |
| `owner_umo` | 本机主人私聊 | 提醒投递目标 |
| `weather_tool_enabled` | true | 是否注册按需天气工具 |

> 坐标用市中心点而不是区县名：Open-Meteo 的地理编码对某些区县名不敏感
> （会返回福建/浙江的同名村），所以必须用坐标。

## 命令（仅所有者私聊）

- `/天气关怀 状态` —— 查看配置与上次判断结果
- `/天气关怀 测试` —— 立即试算（**只报告，不发送**）
- `/天气关怀 强制发送` —— 强制投递一条提醒（用于验证投递链路）

## 依赖

- `aiohttp`（AstrBot 自带的运行时依赖）
- 需要 `xavier_reminder` 插件在线（提醒投递依赖它）
